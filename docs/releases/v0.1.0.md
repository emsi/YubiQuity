# YubiQuity v0.1.0

First public release: a software FIDO2 security key for Linux with an encrypted
vault and native desktop approval prompts. It uses the normal external-key path
in unmodified browsers.

## Install on Ubuntu 24.04 amd64

Download `yubiquity_0.1.0-1_amd64.deb` below, then run in its directory:

```bash
sudo apt install ./yubiquity_0.1.0-1_amd64.deb
sudo yubiquity-setup "$USER"
```

After first setup, save your work and reboot once so the desktop and browsers
receive the new group membership. Open **YubiQuity** from the application menu
and create or open your vault. No development toolchain or browser download is
needed. Existing vaults and PINs remain usable without a reset.

The package includes the GUI, backend, runtime dependency declarations, UHID
module configuration, scoped device rules and Firefox Snap authorization rule.
The setup command grants only the named user access and connects Firefox Snap's
security-key interface when that browser is installed.

## Included

- ES256 passkeys, discoverable credentials and multiple accounts.
- Encrypted Argon2id/XChaCha20-Poly1305 vaults with atomic saves.
- Native approval dialogs, tray operation and KDE X11/Wayland workspace support.
- Standard browser PIN prompts; unlimited PIN and passphrase attempts, with no
  temporary or permanent lockouts, cooldowns or automatic erasure.
- No fixed credential-count cap; a 1 MiB serialized vault limit remains.
- CLI operation and diagnostics alongside the desktop app.

This is a software testing tool. It does not provide hardware key protection or
trusted manufacturer attestation. Unlimited PIN attempts intentionally differ
from the standard CTAP lockout policy. Vault merging and automatic synchronization
are not included in this release.

`SHA256SUMS` covers the `.deb` and `build.json`. The manifest identifies the source
commit, compiler, runtime dependencies and packaged executable hashes. Assets are
not separately signed. GitHub supplies the tagged source archives below.

Validation includes the 79 Rust tests, real UHID PIN/vault/control tests, stock
Firefox recovery flows, isolated desktop tests, package dependency/content checks
and setup-script tests in a disposable chroot. No user vault is included.
